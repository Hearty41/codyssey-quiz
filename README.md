# 🎯 나만의 파이썬 퀴즈 게임(넌센스 퀴즈)

코디세이 E1-2 파이썬 기초 및 Git 워크플로우 학습 미션 프로젝트입니다.
Python 객체지향 프로그래밍(OOP)과 JSON 파일 입출력을 활용해 만든 콘솔 기반 넌센스 퀴즈 게임입니다.

## ✨ 주요 기능
1. **퀴즈 풀기**: 등록된 퀴즈를 순서대로 풀고 즉시 정답 여부와 최종 점수(100점 만점)를 확인합니다.
2. **퀴즈 추가**: 새로운 문제와 4개의 선택지, 정답 번호를 직접 등록할 수 있습니다.
3. **퀴즈 목록**: 현재 저장된 전체 퀴즈 목록을 한눈에 조회합니다.
4. **점수 확인**: 지금까지 달성한 최고 점수를 확인합니다.
5. **데이터 자동 저장 및 복구**: `state.json` 파일에 퀴즈 목록과 최고 점수를 자동 저장하며, 파일이 없거나 손상된 경우 기본 퀴즈 데이터로 안전하게 복구합니다.

## 📁 파일 구조
- `main.py` : 기본 퀴즈 데이터를 초기화하고 게임을 실행하는 시작 파일
- `quiz.py` : 개별 퀴즈 문제, 선택지, 정답 검증을 담당하는 `Quiz` 클래스
- `game.py` : 메뉴 출력, 입력값 예외 처리, 게임 진행, JSON 저장/불러오기를 담당하는 `QuizGame` 클래스
- `state.json` : 추가된 퀴즈 목록과 최고 점수가 저장되는 데이터 파일

## 🚀 실행 방법
터미널(PowerShell 등)에서 프로젝트 폴더로 이동한 뒤 아래 명령어를 입력합니다.

```bash
python main.py
